# FizzBuzz 1〜50

1 から 50 までの数値を対象にした、モダンなデザインの FizzBuzz Web アプリケーションです。

---

## 概要

このプロジェクトは、プログラミングの古典的な課題である「FizzBuzz」を視覚的かつインタラクティブに確認できる Web ページです。  
外部ライブラリへの依存はなく、HTML / CSS / JavaScript のみで構成された単一ファイルで動作します。

---

## 主な機能

- **カード・グリッド表示**: 1 〜 50 の結果をレスポンシブなカード形式で一覧表示
- **カラーバッジ色分け**:
  - **Fizz** (3の倍数): スカイブルー
  - **Buzz** (5の倍数): エメラルドグリーン
  - **FizzBuzz** (15の倍数): ローズ/パープルのグラデーション
  - **数値**: 落ち着いたスレートグレー
- **フィルター絞り込み機能**:
  - 「すべて」「FizzBuzz」「Fizz」「Buzz」「数値のみ」のボタンで表示を即座に切り替え可能
  - 各カテゴリの該当件数をバッジで表示
- **完全スタンドアロン**: 外部依存（CDN や npm パッケージ）なしで、オフライン環境でも動作

---

## FizzBuzz ルール

| 条件 | 出力 | 対象の例 |
| :--- | :--- | :--- |
| 15 の倍数（3 と 5 の公倍数） | **FizzBuzz** | 15, 30, 45 |
| 3 の倍数 | **Fizz** | 3, 6, 9, 12, 18, ... |
| 5 の倍数 | **Buzz** | 5, 10, 20, 25, 35, ... |
| 上記以外 | **数値そのまま** | 1, 2, 4, 7, 8, ... |

## 使い方

1. リポジトリをクローンまたはダウンロードします。
   ```bash
   git clone git@github.com:samichan08/1118-fizzbuzz.git
   cd 1118-fizzbuzz
   ```

2. `index.html` をお好みの Web ブラウザ（Chrome、Edge、Safari、Firefox 等）で開きます。
   - ダブルクリックで開くか、ブラウザウィンドウへドラッグ＆ドロップしてください。
